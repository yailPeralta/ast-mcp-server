### Conventions

- Branches: `feat/421-spike`, `feat/421-typecheck-preflight` (2a), `feat/421-typecheck-worker` (2b), `feat/421-wiring`, `docs/421-template-diagnostics`. Each stacks on the previous (stacked-to-main, PR N targets the branch of PR N-1; retarget to main as each merges).
- One `type:*` label per PR (`type:feature` for 1, 2a, 2b and 3, `type:docs` for 4). `Refs #421` on PRs 1, 2a, 2b and 3, `Closes #421` on PR 4 only.
- Conventional commits, one work unit per commit (RED test and GREEN code of one behavior may share a commit; no AI attribution).
- Strict TDD: RED then GREEN then REFACTOR inside each PR. A RED task is committed failing locally and made green by the paired GREEN task before push.
- Every PR runs: `yarn typecheck && yarn lint && yarn format:check` (filtered to tracked files, for example `yarn prettier --check $(git ls-files '<globs>')`, because untracked `.claude/` and unrelated files fail the global check) plus the vitest targets listed per PR.
- Spec sync: tick the matching scenario in the delta specs when its task lands.
